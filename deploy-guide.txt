91: 八、App 内初始配置
92: 首次打开 App 后，进入底部导航「设置」页面，依次配置：
94: 8.1  抖音 Cookie（必填）
95: 用 Chrome/Edge 打开 www.douyin.com 并登录
96: 按 F12 打开开发者工具 → Application → Cookies → www.douyin.com
97: 找到并复制全部 Cookie 字符串（含 sessionid 字段）
98: 粘贴到 App 设置页「抖音 Cookie」输入框并保存
100: ⚠️ Cookie 有时效（通常30天），过期后需重新获取配置。
102: 8.2  AI 提供商（至少配置一个）
103: 点击「AI 提供商」→「添加」
104: 填写名称（如：DeepSeek）、API Endpoint（如：https://api.deepseek.com）、API Key
105: 点击「测试连接」自动获取可用模型列表
106: 选择模型后保存
108: 推荐 DeepSeek（性价比高），API Endpoint: https://api.deepseek.com
110: 8.3  硅基流动 API Key（可选，用于完整逐字稿）
111: 访问 https://siliconflow.cn 注册账号
112: 获取 API Key（格式：sk-xxxxxxxx）
113: 填入设置页「语音识别」→「硅基流动 API Key」并保存
115: 使用模型：FunAudioLLM/SenseVoiceSmall（中文优化，有免费额度）

146: 十、常见问题
147: Q: 数据获取失败，提示 Cookie 无效
148: A: 重新从浏览器复制抖音 Cookie，注意要完整复制（通常 6000+ 字符），在设置页更新后重试。
150: Q: AI 分析失败或无响应
151: A: 检查 AI 提供商配置是否正确，可在设置页点击「测试连接」验证。注意 API Key 不要带多余空格。
153: Q: 逐字稿只显示视频描述而非真实文字
154: A: 需配置「硅基流动 API Key」才能进行音频转录。未配置时系统返回视频描述作为兜底内容。
156: Q: Edge Function 部署失败
157: A: 确认 supabase link 使用了正确的 project-ref，并已执行 supabase login。检查网络是否能访问 supabase.com。
159: Q: pnpm install 报错
160: A: 确认 Node.js ≥ 18，pnpm ≥ 8。如果出现 peer dependency 警告可忽略，不影响运行。
163: 十一、注意事项
164: 本 App 仅供个人学习/研究使用，请遵守抖音平台使用条款
165: Cookie 等敏感信息仅存储在你自己的 Supabase 数据库中，不会外传
166: 硅基流动免费额度有限，建议充值少量余额（¥10 可用较长时间）
167: 若需多人使用，建议在 Supabase 启用 RLS（行级安全）策略
168: 定期更新 Cookie 以保持数据访问正常
